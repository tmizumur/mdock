# Mdock

AI が書いた Markdown を、VS Code より速く・快適に読むためのデスクトップアプリです。
フォルダを開いてツリーからファイルを選び、2 画面に並べて読み比べられます。ちょっとした編集もできます。

## 主な機能

- フォルダを開く（メニュー / ⌘O / ウィンドウにドロップ）
- 左にファイルツリー（「.md のみ」で Markdown だけに絞り込み）。1 万ファイルでも軽い（見えている行だけ描く）。↑↓ で移動、→← で開閉、Enter で開く
- ツリーの右クリック: 新規ファイル / 新規フォルダ / 名前を変更（その場で入力）/ ゴミ箱に入れる / Finder で表示 / パスをコピー / 相対パスをコピー（開いているフォルダの中だけ）
- 「表示」メニューで隠しファイル（. で始まるもの）の表示を切り替え（.git や node_modules は出しません）
- Finder で .md / .markdown / .mdx をダブルクリック・「このアプリで開く」で Mdock が開く。フォルダを開いていなければ、そのファイルのフォルダを開く
- ⌘N で新しいウインドウ。ウインドウごとに別のフォルダを開け、再起動すると全ウインドウが戻る
- 印刷 / PDF に書き出し（メニュー「ファイル」またはペインのプリンターのボタン）。プレビュー本文だけをライト配色で印刷し、印刷ダイアログの「PDF として保存」で PDF にできる
- Markdown のプレビュー（表・チェックボックス・コードハイライト・Mermaid 図・数式 `$...$` / `$$...$$`）
- ファイル内検索（⌘F）。表示中は一致箇所をすべてハイライト、編集中はエディタの検索
- コードブロックの右上にコピーボタン
- 相対パスの画像を表示。md 同士のリンクはアプリ内で開き、`#見出し` へはスクロール、外部 URL はブラウザで開く
- プレビュー右端の帯で、見出しの位置と今見えている範囲がわかる（クリック・ドラッグで移動）。ペインの上には今いる見出しを表示
- 「表示」メニューで文字サイズ・本文の幅（標準 / 広い / 全幅）・長い行の折り返しを設定（アプリ全体で保存）
- 1 万行程度の大きな Markdown でも固まらないよう、コードの色付けや図は見えたところから描く
- 画面分割（VS Code と同じ）: タブやツリーのファイルをペインへドラッグし、上下左右の端に落とすとその方向に新しいペインを作って開く（中央ならそのペインのタブに）。何画面にでも入れ子で分割でき、境界をドラッグして大きさを調整。ペインの最後のタブを閉じるとペインも消えて隣が広がる。ツールバーのボタン（1 画面 / 左右 / 上下 / 3 分割）はレイアウトのリセット用
- ペインごとにタブ。ツリーのクリックは今のタブで開き（既に開いていればそのタブへ）、⌥+クリックで新しいタブ。中クリックで閉じる、ドラッグで並べ替え・ほかのペインへ移動・分割
- タブを右クリック →「隣のペインと比較」で、2 つのファイルの差分を左右に並べて表示
- タブごとに「表示 / 編集 / 編集＋プレビュー」を切り替え、⌘S で保存。編集＋プレビューはエディタとプレビューのスクロールが連動
- 未保存の変更があるタブを閉じるとき・アプリを終了するときは「保存 / 保存しない / キャンセル」を確認
- ファイルが外から書き換わったら自動で再表示（未保存の編集は上書きしません）
- 再起動・アップデートしても、前回の状態をそのまま復元（フォルダ、各ペインのタブ・表示モード・スクロール位置、画面分割、ツリーの幅、未保存の編集、ウィンドウの位置とサイズ）

## 操作

| 操作 | キー |
| --- | --- |
| フォルダを開く | ⌘O |
| 新しいウインドウ | ⌘N |
| ツリーのファイルを隣のペインに開く（1 画面なら右に分割） | ⌘+クリック |
| ツリーのファイルを新しいタブで開く | ⌥+クリック |
| タブを閉じる | ⌘W |
| 前 / 次のタブ | ⌘⇧[ / ⌘⇧] |
| 今のペインを右に分割（今のタブを複製） | ⌘\ |
| n 番目のペインを選ぶ（画面上の順。1 つ先なら右に新しいペイン） | ⌘1 〜 ⌘9 |
| 表示 / 編集 切り替え | ⌘E |
| ファイル内を検索（Enter / ⇧Enter で次 / 前、Esc で閉じる） | ⌘F |
| 文字を大きく / 小さく / 標準に戻す | ⌘+ / ⌘- / ⌘0 |
| 保存 | ⌘S |

## アップデート

main にマージすると GitHub Actions が自動でビルドし、[Releases](https://github.com/tmizumur/mdock/releases) に新しい版（0.1.<番号>）を公開します。
Mdock は起動時と1時間ごとに新しい版を確認し、あればツールバーに「vX に更新」ボタンが出ます。押すと新しい版の変更内容（前回のリリースからマージされた PR の一覧）が表示され、「更新して再起動」で更新します。開いていたフォルダやウィンドウ位置はそのまま戻ります。

リリースの本文と、アプリに表示される変更内容（latest.json の notes）は、GitHub Actions が前回のリリース以降にマージされた PR のタイトルから自動で作ります。

### 最初に1回だけ必要な準備

更新ファイルの署名に使う鍵を GitHub の Secrets に登録します。

```bash
gh secret set TAURI_SIGNING_PRIVATE_KEY --repo tmizumur/mdock < ~/.tauri/mdock.key
```

鍵（`~/.tauri/mdock.key`）は他人に渡さないでください。なくすと、それ以降の更新を配れなくなります。

## 開発

必要なもの: Node.js 20 以上、Rust（`rustup`）、Xcode Command Line Tools

```bash
npm install
npm run tauri dev      # 開発モードで起動
npm run tauri build    # .app / .dmg を作成（src-tauri/target/release/bundle/）
```

## 技術構成

- [Tauri 2](https://tauri.app/)（Rust）: ファイル読み書き、フォルダ監視（notify）
- React + TypeScript + Vite
- markdown-it / Shiki / Mermaid（Shiki と Mermaid は必要になってから読み込み）
- CodeMirror 6（編集モードにしたときだけ読み込み）
- react-resizable-panels
