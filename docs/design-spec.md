# mdock デザイン仕様

## 方針

Zed や Linear のような静かな道具感。

- ダークモードのみ。ライトモードと、設定のテーマ切り替えは削除する。`prefers-color-scheme` での切り替えもやめ、Shiki と Mermaid もダーク配色に固定する。
- 情報は常に見える場所に置く。
- タイトルバーを消して上のバーと一体化する。
- 角丸は大きめ、動きは控えめ。

## 文字

- アプリは Mac 標準のゴシック（`-apple-system, "SF Pro", "Hiragino Sans"`）。
- 本文 15px、行間 1.8。
- 見出し1 28px 太さ700、見出し2 20px 太さ600 で下に細い線。
- ツリーとタブ 12.5〜13px。
- ラベル 11px 太さ600 字間 0.06em で `--fg-faint`。
- コードは等幅 13px（`ui-monospace, "SF Mono", Menlo`）。

## 角丸

小さな部品 7px、タブとツリーの行 8px、カードとコードブロック 12px、ダイアログ 16px、ウィンドウの内側 14px 程度。

## 動き

- ホバーと選択の色変化 120ms。
- フォルダ開閉・タブ移動・分割 180ms ease-out。
- ダイアログは 200ms で少し拡大しながら表示。
- macOS の「視差効果を減らす」（`prefers-reduced-motion`）がオンなら止める。
- 設定に「アニメーション」のオン/オフを追加。

## ウィンドウ枠

`tauri.conf.json` でタイトルバーを隠し（`titleBarStyle: "Overlay"` と `hiddenTitle`、信号のボタンは残す）、高さ 44px の上のバーを自作する。

左から：

1. 信号のボタン分の余白
2. サイドバー開閉ボタン
3. フォルダ名（太字 13px、▾付き、押すとフォルダを開く・最近のフォルダ）
4. ブランチ名の小さな丸いバッジ（git リポジトリのときだけ）
5. 空き
6. レイアウトのセグメント（1画面・左右・上下のアイコン、背景 `--bg-elev`、角丸 10px）
7. 設定の歯車
8. 更新があるときだけ「v0.x.x に更新」の丸いボタン（背景 `--accent`、文字 `--bg`）

バーの空き部分はドラッグでウィンドウを移動できる（`data-tauri-drag-region`、必要な権限も追加）。ダブルクリックで拡大縮小。

## サイドバー

幅 248〜280px、背景 `--bg-side`。

- 上に「エクスプローラー」ラベルと、新規ファイル・新規フォルダ・すべて閉じるのアイコンボタン（26px 角、角丸 7px）。
- その下に「.md のみ / すべて」のセグメント切り替え。
- ツリーの行は高さ 28px、角丸 8px、左右に 6px の余白、選択中は背景 `--tree-selected` と太字。
- git で変更・新規のファイルは名前を色付けし、右端に M / U。変更を含むフォルダは右端に点。
- サイドバー下部に「アウトライン」パネル（今のペインの見出し一覧、今読んでいる見出しは `--accent`、クリックでジャンプ）。

## ペイン

- 上にタブバー（高さ 40px、下に `--border` の線）。
- タブは高さ 30px、角丸 8px。選択中は背景 `--bg-elev` と細い枠（`0 0 0 1px var(--bg-hover)`）と太字、他は `--fg-muted` で背景なし。
- 未保存は ● を `--accent` で、選択中のタブだけ × を出す。
- タブバー右端に「表示 / 編集 / 並べて」のセグメント切り替え。
- その下に高さ 30px のパンくず（フォルダ > ファイル > 見出し、最後だけ `--fg`）。
- 本文は左右 40px の余白。
- 右端の位置表示の帯は幅 12px、見出しの目盛りと、見えている範囲を `--accent-soft` の角丸の枠で。
- コードブロックは角丸 12px、細い枠、右上にコピーボタン（角丸 8px）。
- エディタは背景 `--bg`、行番号 `--fg-faint`、今の行は少し明るい背景。
- ペインの区切りは 1px の `--border`、ドラッグ分割の落とし先の表示も角丸と `--accent-soft` に合わせる。

## ステータスバー

高さ 26px、背景 `--bg-side`、文字 11.5px `--fg-faint`、常に表示（設定でオフにもできる）。

左から：

1. ライブ反映の状態（緑の点と「ライブ反映中」）
2. ブランチ名
3. 変更数（`M n` を `--git-modified`、`U n` を `--git-added`）
4. 空き
5. 今のファイルのパス（12px、`--fg-muted`）
6. 文字数と読了時間の目安
7. 「Markdown · UTF-8」
8. 文字サイズ

## 設定画面

- 幅 820px 程度、角丸 16px、背景 `--bg-side`、枠 `--bg-hover`、大きな影。
- 左に分類のナビ（表示・エディタ・ファイル・更新・ショートカット、各行 34px 角丸 9px、選択中は薄い青の背景）。
- 右に項目。各項目は左に名前と小さな説明、右に操作（セグメント切り替え、−/+、トグルスイッチ 40x24 でオンは `--accent`）、項目の間は細い線。
- テーマの項目は削除し、「アニメーション」と「ステータスバー」を追加。

## 壊してはいけない既存の機能

タブ、ドラッグ分割、差分、編集＋プレビュー、検索、数式、git 表示、ライブ反映、設定の保存、セッション復元、更新ボタン。
